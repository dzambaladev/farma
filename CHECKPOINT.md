# Farma — checkpoint проекта

**Дата:** 2026-11-26  
**Репозиторий:** https://github.com/dzambaladev/farma  
**Ветка:** main

## Цель
Работающая первая бета независимого каталога лекарственных препаратов Украины. Приоритет — небольшой качественный каталог и работающий поиск, а не идеальная модель или масштабная платформа.

## Принятые решения
- Амоксиклав — текущий образец JSON-структуры.
- Виагра приведена к структуре Амоксиклава; фактические неопределённости и вторичные источники сохранены.
- Статический сайт на Node.js build script; JSON в GitHub остаётся источником истины.
- Netlify — целевой простой хостинг.
- До выбора домена и проверки данных сайт по умолчанию закрыт от индексации (noindex,nofollow).
- Нет цен, аптечных остатков, медицинских рекомендаций и автоматического подбора замен.

## Что сделано
- data/products/viagra.json: 3 продукта, 3 регистрации, 18 SourceAssertion; структура выровнена с Амоксиклавом.
- DATA_MODEL.md: описаны реальные поля текущего MVP и временное хранение последнего регистрационного наблюдения в Registration.
- Добавлены package.json, netlify.toml, src/site.css, src/search.js, scripts/build.mjs.
- Генератор строит главную страницу, карточки продуктов, страницы действующих веществ, поисковый индекс и robots.txt.
- Добавлено предупреждение о бета-статусе на страницах препаратов.
- Добавлен GitHub Actions workflow .github/workflows/build.yml для проверки сборки.
- README.md и ROADMAP.md обновлены под текущую реализацию.

- CI успешно выполнил `npm run build` и проверил наличие главной, поискового индекса, robots.txt, страниц препаратов и действующих веществ (run #3, commit f0d0754).
- Netlify ещё не подключён, публичный URL не создан.

- Publication gate у исходных датасетов остаётся ready=false; бета не должна индексироваться.
- У Виагры 50 мг подробные сведения и упаковки частично основаны на вторичном источнике; эквивалентности массы цитрата силденафила также требуют проверки по официальной инструкции.

- Минимальный валидатор связей и автоматическая проверка publication gate — следующий технический этап после визуальной проверки беты.
