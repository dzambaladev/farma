# Farma — каталог лекарственных препаратов

Рабочее название проекта. На первом этапе — независимый информационный каталог лекарственных препаратов Украины, не аптечный маркетплейс и не сервис медицинских рекомендаций.

## Цель

Создать компактный, достоверный и машиночитаемый каталог, где каждая лекарственная сущность имеет устойчивую идентичность, структурированные характеристики и проверяемые источники.

Первая задача — проверить, можно ли построить полезный каталог с качественными страницами, доступными обычному поиску и системам AI-поиска, не пытаясь сразу повторить крупные аптечные агрегаторы.

## Принципы MVP

1. **Сущность прежде страницы.** Страница отображает структурированную запись; HTML не является первичным хранилищем истины.
2. **Происхождение данных.** Для значимых утверждений храним источник и дату получения/проверки.
3. **Точность идентификации.** Различаем торговое наименование, действующее вещество, дозировку, форму выпуска и упаковку.
4. **Никаких выдуманных данных.** Неизвестное поле остаётся неизвестным.
5. **Безопасность.** Каталог не диагностирует, не назначает лечение и не предлагает автоматически заменять препараты.
6. **Малые проверяемые шаги.** Сначала одна качественная запись и один законченный сценарий.
7. **Переносимость.** Данные и шаблоны не должны зависеть от конкретного хостинга.

## Границы первого этапа

В MVP входят каталог, страницы отдельных вариантов препарата, структурированные сведения, источники и техническая основа индексации.

Пока не входят цены и наличие в аптеках, бронирование, продажа, персональные рекомендации, автоматическая взаимозаменяемость, отзывы и медицинские консультации.

## Предварительный стек

- GitHub — исходники и контроль изменений;
- Netlify — первоначальный хостинг и сборка из GitHub;
- статическая генерация страниц — предпочтительный старт;
- структурированные файлы данных — источник истины на первом этапе.

Генератор и формат хранения выбираются после проверки модели данных и первого прототипа.

## Документы

- ARCHITECTURE.md — компоненты и поток данных.
- DATA_MODEL.md — сущности и связи.
- SEO_AI.md — доступность для поисковых систем и AI-поиска.
- ROADMAP.md — последовательность этапов.

## Критерий успеха MVP

Для ограниченного набора препаратов пользователь может найти запись, отличить варианты с разными дозировками и формами, увидеть источники и дату проверки, перейти к первоисточнику и открыть страницу, корректно читаемую поисковым роботом.

Попадание в ответы конкретных AI-систем не гарантируется. Мы проектируем данные и страницы так, чтобы их было проще обнаруживать, извлекать и проверять.
